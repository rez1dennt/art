# ART OF ASKING QUESTIONS

Сайт на обычных HTML, CSS и JavaScript по одобренному макету `design/homepage-v1.png`. На стороне посетителя нет фреймворков, библиотек, внешних шрифтов и аналитики.

## Запуск

```sh
npm run build
npm run dev
```

Предпросмотр: http://127.0.0.1:4173 . Открывать через локальный сервер, не через file://: используются чистые URL и модули JavaScript.

## Файлы

- `dist/` — готовые HTML-страницы и ресурсы. Эту папку можно разместить на статическом хостинге.
- `dist/assets/styles.css` — общие стили, адаптив и анимации.
- `dist/assets/app.js` — меню, диалоги, cookie, подготовка обращения.
- `dist/assets/state.mjs` — проверка сохранённого выбора cookie.
- `scripts/home.mjs`, `scripts/services.mjs`, `scripts/legal.mjs` — тексты и шаблоны страниц.
- `scripts/build.mjs` — общие шапка, подвал, диалоги и SEO. После правок шаблонов запустить `npm run build`.
- `qa/` — проверки. Запуск `npm test`.
- `docs/client-information.md` — данные для окончательного запуска.

Для публичного домена задать `SITE_URL=https://ваш-домен` и после утверждения материалов `SITE_LIVE=1`, затем выполнить `npm run build`. Проекты юридических документов не становятся готовыми от изменения этого флага.

Текущая форма не отправляет данные: она явно предлагает скопировать текст. Backend и получатель подключаются после получения реквизитов, окончательного согласия и адресата заявок.
