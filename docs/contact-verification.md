# Проверка формы отправки

- Удалён светлый favicon для тёмной темы. Все семь страниц используют один зелёный PNG с прозрачным альфа-каналом; новое имя файла исключает использование предыдущей белой иконки из кэша.
- Удалён сценарий копирования текста. Форма содержит «Отправить заявку», отдельное неотмеченное согласие, POST-отправку, блокировку повторного запроса, таймаут, подтверждение после ответа сервера и сохранение полей при ошибке.
- Инструкции о подключении перенесены в `contact-integration.md`; в интерфейсе их нет. Юридические шаблоны больше не описывают устаревший сценарий копирования.
- Автотесты: 15 проходят. Для отправки проверены тело POST, подтверждение success:true, отказы HTTP, HTML вместо JSON, отрицательное подтверждение и таймаут.
- Браузер: обязательные поля и согласие блокируют незаполненную заявку. При тестовом запросе к локальному адресу без обработчика показывается обычная ошибка, поля сохраняются, повторная отправка доступна. Успех не имитируется.
- После финальных правок: 7 страниц × 4 ширины (1280, 768, 360, 320), всего 28 проверок — переполнения нет, favicon один, служебных предупреждений в форме нет.
- Форма на 320×800 занимает около 606 px и помещается целиком.
- Фактическая доставка адресату не проверялась: серверный обработчик владелец решил настроить самостоятельно. Тестовые данные браузера очищены перезагрузкой.
- Содержимое двух презентаций повторно сверено; карта всех 18 слайдов находится в `presentation-coverage.md`.
