# Проверка реализации

Проверена текущая версия через локальный HTTP-сервер в браузере Codex.

## Автоматические проверки

- `npm test`: 9 тестов — семь маршрутов с HTML/SEO/локальными ссылками, запрет индексации демонстрации, проверка повреждённого/просроченного/будущего состояния cookie.
- `node --check dist/assets/app.js`: синтаксис JavaScript.
- `node scripts/build.mjs`: создаёт семь страниц без зависимостей.

## Браузер

- Семь маршрутов × 1280, 768, 360, 320 px = 28 проверок после финальных исправлений: горизонтального переполнения нет, на каждой странице один H1, фиксированная шапка находится на top: 0.
- Визуально просмотрены главная 1440/768/320 px, мобильные меню/форма/cookie и начало страницы диагностики 320 px.
- Все фотографии главной загрузились после прокрутки в соответствующие области; начальные пустые кадры вне viewport обусловлены lazy-loading.
- Меню: открытие, повторное открытие, Escape, переход к разделу и переход к форме; диалог остаётся открыт во время анимации закрытия, затем закрывается.
- При открытии меню на 320 px координаты шапки и кнопки не изменились. После закрытия scrollY восстановлен с 4215 до 4215, фокус вернулся к кнопке меню.
- Якорный переход после исправления: верх раздела 101,92 px, низ шапки 78 px. Отступ около 24 px.
- Форма: пустые обязательные поля блокируют действие; тестовое заполнение даёт сообщение о копировании, явно без отправки. Тестовые поля очищены.
- Cookie: сохранение, повторное открытие, удаление выбора, повторное сохранение, сохранение состояния после перезагрузки. После скрытия инициирующей плашки фокус возвращается к видимой ссылке логотипа в шапке.
- Консоль браузера на итоговом проходе: ошибок и предупреждений нет.
- Уважение reduced motion предусмотрено CSS и JS. Отдельные физические устройства, Safari и системное изменение настройки анимации не проверялись.

## Исправленные замечания

- На планшете фотография пересекалась с заголовком: изменена ширина кадра в соответствующем медиадиапазоне.
- Двойная компенсация фиксированной шапки при переходе к якорю: оставлена компенсация только на целевом элементе.
- Потеря фокуса после сохранения cookie из плашки: добавлен видимый резервный элемент.
- Уточнены реальные размеры изображений и дескрипторы srcset.

## Пределы готовности

Backend формы, реальные контакты, публичный домен, реквизиты и окончательные юридические документы ожидают данных владельца. Индексация демонстрации намеренно выключена. Неподтверждённые Lighthouse-баллы или утверждение о проверке всех физических устройств не приводятся.
