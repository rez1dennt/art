# Доработки по замечаниям к мобильной версии

- Форма на 360×800: исходное содержимое 922 px, новое 598 px; начальная форма помещается без внутренней прокрутки. Компания сохранена как необязательное раскрываемое поле.
- Cookie-настройки на 320×800: 596 px, помещаются целиком.
- Меню — полноширинная панель, выезжающая сверху за 440 мс. По закрытию остаётся в DOM до завершения transform-перехода; фон исчезает вместе с панелью.
- Три полоски превращаются в крестик на том же DOM-элементе. Кнопка временно перемещается в верхний слой native dialog, сохраняет экранные координаты и возвращается в шапку после закрытия.
- Проверка 360 px: координаты кнопки до и после открытия одинаковы — x=277, y=14,5, 48×48. Прокрутка до и после закрытия — 3965 px. Фокус возвращён кнопке.
- Надпись на фотографии получила светлую контрастную подложку. Фотография не изменена.
- Надпись логотипа слегка облегчена локально без изменения монограммы. Пиксельное сравнение монограммы: 0 отличий. Неудачная генеративная вариация не используется.
- Новые favicon для светлого и тёмного оформления имеют настоящий альфа-канал, без прямоугольной подложки.
- Повторены 28 проверок маршрутов на 1280/768/360/320 px: нет горизонтального переполнения, фиксированная шапка на месте, кнопка меню одна.
- Автоматические проверки: 11 тестов; добавленные проверки сначала выявили отсутствие третьей полоски и компактного необязательного поля, после правок проходят.

Изменения доступны в локальном предпросмотре. Автоматическое повторное размещение существующего сайта не запускалось.
