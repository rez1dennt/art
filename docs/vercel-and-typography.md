# Vercel и переносы текста

## Исправление сборки Vercel

В исходном логе `npm run build` успешно создавал `dist`, но Vercel искал каталог `public`. В корне добавлен `vercel.json`:

- `framework: null` — обычный статический сайт;
- `buildCommand: npm run build`;
- `outputDirectory: dist`;
- `trailingSlash: true` — URL каталогов с index.html.

Настройка outputDirectory в файле переопределяет настройку проекта: https://vercel.com/docs/project-configuration/vercel-json#outputdirectory . Root Directory проекта должен оставаться корнем репозитория, где находится package.json. Сборка в Vercel запускается из обновлённого main; локально проверена генерация всех страниц и конфигурация результата. Успешная облачная публикация отдельно не заявляется без статуса Vercel.

## Типографика

- Основной шрифт — Manrope. Georgia оставлен вторым, контрастным шрифтом для крупных цифр, обозначений продуктов и акцентных заголовков. Похожие дополнительные гротески не добавлялись.
- Удалён принудительный перенос перед словом «деньги». «Теряет деньги» и «следующего шага» сохраняются как цельные сочетания.
- Межбуквенные интервалы сделаны менее плотными; текст сбалансирован по строкам.
- Мобильный заголовок «Где теряется стоимость» уменьшен и помещается одной строкой на проверенных ширинах. Главный заголовок переносится по смыслу, сохраняя читаемый размер.
- Все декоративные стрелки удалены со всех HTML-страниц.
