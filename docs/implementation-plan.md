# Реализация одобренного макета

Цель: статический сайт ART OF ASKING QUESTIONS на HTML, CSS и JavaScript по design/homepage-v1.png.

1. Подготовить три самостоятельные фотографии, извлечь исходный логотип и оптимизировать изображения в WebP.
2. Создать общие CSS-токены, шапку, подвал, доступные диалоги, мобильную навигацию и управление cookie. Сохранить светлую палитру, мягкие радиусы и разные композиции разделов макета.
3. Сверстать главную, /diagnostika/, /strategiya/ с полной информацией двух презентаций; /privacy/, /cookies/, /consent/, /terms/ с пометкой проекта для документов, зависящих от реквизитов.
4. Сделать SEO в исходном HTML: отдельные title/description/H1, канонические URL, JSON-LD, breadcrumbs, sitemap и robots. До подтверждения домена и юридических данных оставить демонстрацию noindex.
5. Проверить все маршруты и взаимодействия на 1440/1280/768/360/320 px, клавиатуру, reduced motion, отсутствие переполнения и ошибок ресурсов.
6. Показать результат, передать список недостающих данных. Заявки не отправлять, пока получатель не настроен; не имитировать успешную отправку.

Факты: 10 рабочих дней / 3 senior-эксперта / 10 млн рублей для V+; 25 рабочих дней / 3 эксперта / вознаграждение после результата для V+2. Период результата 1–5 лет указан как опциональный; последующее сопровождение оплачивается отдельно.
